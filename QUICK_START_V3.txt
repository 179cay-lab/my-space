🔐 SETUP (First Time)
─────────────────────────────────────────────────────────────────
1. Open index.html in browser
2. Default PIN: 6089
3. Go to ⚙️ Settings tab
4. Optional: 
   - Change PIN
   - Disable passcode for instant access
   - Enable/disable as needed

💰 TAB 1: EXPENSES (Chi tiêu)
─────────────────────────────────────────────────────────────────
QUICK WORKFLOW:
1. Click "📸 Chụp ảnh" or "📁 Upload ảnh"
2. Select/capture photo → MODAL OPENS
3. Choose category
4. Enter product name
5. Enter price (see suggestions)
6. Click suggestion or type custom
7. Add optional note
8. Click "Lưu chi tiêu" → Done!

DIFFERENCES FROM v2:
❌ No more scrolling
✅ Modal appears immediately after photo
✅ File upload added (not just camera)
✅ Images 5-6x more compressed

📋 TAB 2: TODOS (Công việc)
─────────────────────────────────────────────────────────────────
NEW TODOIST-LIKE FEATURES:
• Priority: 🔴 High | 🟡 Medium | 🟢 Low
• Due Date: With tracking (overdue, today, days left)
• Category: Personal, Work, Health, Other
• Description: Add detailed notes
• Recurring: Daily, Weekly, Monthly, None
• Status Filter: Active, Done, Overdue
• Search: Type to find instantly
• Edit: Click ✏️ to modify

BADGES EXPLAINED:
🔴 Cao = High priority
🟡 Trung = Medium priority
🟢 Thấp = Low priority
⏰ Quá hạn = Past due date
📅 Hôm nay = Due today
📅 Ngày mai = Due tomorrow
📅 5d = Due in 5 days
🔁 daily/weekly/monthly = Recurring task

ACTIONS:
✅ Click circle to complete/uncomplete
✏️ Edit button to modify
🗑️ Delete button to remove

📊 TAB 3: TODO STATS
─────────────────────────────────────────────────────────────────

📈 TAB 4: CHI TIÊU STATS
─────────────────────────────────────────────────────────────────

⚙️ TAB 5: SETTINGS
─────────────────────────────────────────────────────────────────
PASSCODE:
• Toggle: ON/OFF
• Change PIN: Only when ON
• Default: 6089

EXPORT:

RESET:

💡 PRO TIPS
─────────────────────────────────────────────────────────────────
1. Disable passcode at home for instant access
   (Settings → Passcode → Toggle OFF)

2. Use high priority for urgent todos
   (Shows with 🔴 red badge)

3. Set due dates for important tasks
   (Track overdue automatically)

4. Search todos instantly
   (Type in search box)

5. Export weekly backups
   (Settings → Xuất)

6. Photos are tiny (10-15 KB each!)
   (vs 50-80 KB in v2.0)

7. Recurring todos for habits
   (Daily/Weekly/Monthly)

8. Notes on expenses
   (Add details to each expense)

─────────────────────────────────────────────────────────────────

EXAMPLES:

❓ TROUBLESHOOTING
─────────────────────────────────────────────────────────────────
Modal not appearing?
  → Reload page
  → Check browser permissions
  → Clear cache

Forgot PIN?
  → Settings → Passcode OFF (if you remember any)
  → Otherwise: Clear localStorage

Storage full?
  → Settings → Xuất (export backup)
  → Reset all data
  → Start fresh

Images too small?
  → Still readable (highly compressed)
  → Quality is intentional (storage savings)
