## 🚀 Getting Started

### Installation
1. Double-click `index.html`
2. Use PIN: `6089`
3. Or go to Settings → Disable passcode

### First Steps
1. Go to Expense tab → Click 📸 or 📁
2. Take/upload photo → Fill modal form
3. Go to Todo tab → Click "+ Thêm Todo"
4. Set priority, due date, etc. → Create
5. Check stats in Stats tabs

## 📞 Support

### Common Issues

**Forgot PIN?**
→ Go to Settings, toggle Passcode OFF

**Storage full?**
→ Settings → Xuất (export backup) → Reset all

**Images not showing?**
→ Reload page, clear cache

**Need to reset?**
→ Settings → Xoá (delete all) → Confirm twice
